小许音乐桥接 Windows 安装说明

系统要求：Windows 10 或 Windows 11，x64 版本。

1. 将压缩包完整解压到一个固定文件夹，不要直接在压缩包内运行文件。
2. 双击运行 install.bat，完成本机通信程序安装。
3. 在 Chrome 地址栏打开 chrome://extensions，开启“开发者模式”。
4. 点击“加载已解压的扩展程序”，选择解压目录中的 extension 文件夹。
5. 请保留整个解压文件夹。如果移动了文件夹，请在新位置重新运行 install.bat。
6. 删除文件前，请先运行 uninstall.bat，再移除 Chrome 中的扩展程序和解压文件夹。
